QuickPress — خطوات التشغيل على ويندوز 10 (بالنقر المزدوج، دون إنترنت)
=====================================================================

1) فك ضغط المجلد QuickPress في أي مكان (مثل سطح المكتب).
2) افتح المجلد وانقر مرتين على index.html.
   - يفتح المرجع بالعربية افتراضياً.
   - إن كنت used الإنجليزية آخر مرة (محفوظة في المتصفح)، سيفتح بالإنجليزية.
3) التنقل: من التبويبات الأربعة أعلى الصفحة (ويندوز / Alt / أوفيس / الجدول الشامل).
4) تبديل اللغة: زر «العربية | EN» أعلى الصفحة — يفتح الصفحة نفسها باللغة الأخرى ويحفظ اختيارك.
5) البحث: اكتب في مربع البحث بالعربية أو بالمفاتيح:
   - «اعادة» تجد «إعادة» (التطبيع العربي: الهمزات والتاء المربوطة والتشكيل).
   - «ctrl c» أو «Ctrl+C» كلاهما يجد Ctrl + C.
   - زر «/» أو Ctrl + K ينقلان المؤشر إلى البحث.
6) المفضلة: انقر النجمة على أي بطاقة. تظهر المفضلة في كل الصفحات واللغات والجدول الشامل
   وتُحفظ في المتصفح (localStorage) حتى بعد إغلاقه.
7) تصدير المفضلة: زر «تصدير المفضلة» ينزّل ملف CSV بترميز UTF-8 مع BOM
   (quickpress_fav_shortcuts.csv بالعربية / quickpress_fav_shortcuts_en.csv بالإنجليزية).
8) الطباعة: زر «طباعة» في شريط الأدوات. في الجدول الشامل تُطبع قائمة الجدول فقط.

ملاحظات مهمة:
- المشروع يعمل دون خادم ودون إنترنت: كل الخطوط والأيقونات والصور محلية داخل assets.
- لا تحتاج Node.js لتشغيله إطلاقاً.
- لأعداء الصيانة فقط (اختياري تماماً): لتعديل بيانات الاختصارات عدّل assets/js/data.js مباشرة.
  ولبناء CSS من جديد بعد أي تعديل تصميمي، ثبّت Node.js من nodejs.org ثم من داخل المجلد:
     npm install
     npm run build:css
- لفحص سلامة البيانات بعد أي تعديل:  node check-data.js   و   node check-import.js

ملفات السجلات (مطلوبة في المطالبة):
- import-notes.txt: سجل استيراد ملف PDF المرجعي (الدموج والحذوف المبرر وجدول الأعداد).
- needs-review.txt: سجل الشك والمراجعة (الفروقات الموثقة والقرارات).
