QuickPress — طريقة بناء ملف EXE لأجهزة ويندوز باستخدام إلكترون
================================================================

المتطلبات (مرة واحدة فقط):
1) تثبيت Node.js نسخة LTS من الموقع الرسمي:  https://nodejs.org
   (أثناء التثبيت اترك كل الخيارات الافتراضية كما هي ثم أعد تشغيل الجهاز)

خطوات البناء:
1) ضع مجلد التطبيق في أي مكان مناسب، مثلاً:
   D:\Building Applications\QuickPress
   ملاحظة: يمكنك فك ضغط QuickPress-Electron.zip فوق مجلدك الحالي مباشرة،
   فالملفات الجديدة (main.js و package.json و التعليمات) لا تحذف أي ملف موجود.

2) افتح نافذة الأوامر داخل مجلد التطبيق:
   - افتح مجلد QuickPress في مستكشف الملفات
   - انقر في شريط العنوان فوقه واكتب:  cmd  ثم اضغط Enter

3) نزّل أدوات البناء (يحتاج اتصالاً بالإنترنت، أول مرة فقط، قد يستغرق بضع دقائق):
   npm install

4) ابنِ ملفات exe:
   npm run dist
   (وهذا الأمر مطابق تماماً لـ:  npx electron-builder --win )

5) ستجد النتيجة داخل مجلد جديد اسمه dist:
   - QuickPress-Setup-1.0.0.exe     ← نسخة التثبيت (مع اختصار سطح المكتب وقائمة ابدأ)
   - QuickPress-Portable-1.0.0.exe  ← نسخة محمولة تعمل بدون تثبيت، تنفع للفلاشة

لتجربة التطبيق داخل إلكترون قبل البناء (اختياري):
   npm start

بناء نسخة واحدة فقط:
   npm run dist:nsis      ← نسخة التثبيت فقط
   npm run dist:portable  ← النسخة المحمولة فقط

ملاحظات مهمة:
- عند تشغيل ملف exe لأول مرة قد تظهر نافذة تحذير من Windows SmartScreen لأن الملف
  غير موقّع رقمياً (التوقيع يحتاج اشتراكاً مدفوعاً)؛ اضغط «More info» ثم «Run anyway».
- ملف exe الناتج يعمل على ويندوز 10 و 11 (64-bit) ولا يحتاج Node.js ولا إنترنت،
  وكل بيانات التطبيق (الخطوط والصور والاختصارات) داخل الملف نفسه.
- أيقونة النافذة وشريط المهام وملف exe واختصارات سطح المكتب كلها تأخذ الأيقونة
  من الملف:  assets/img/logo.ico
- المفضلة والإعدادات تُحفظ تلقائياً لكل مستخدم في ويندوز وتبقى بعد الإغلاق.
- إن ظهر خطأ أثناء npm install بسبب سياسة التنفيذ في PowerShell، استخدم CMD
  العادي بدلاً منه.
